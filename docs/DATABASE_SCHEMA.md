# Database Schema Documentation

## Relational Data Models (SQLAlchemy / SQLite / PostgreSQL)

### 1. `users` Table
Stores administrative and analyst user accounts with role-based access control (RBAC).

| Column | Type | Constraints | Description |
|---|---|---|---|
| `id` | `VARCHAR(36)` | PRIMARY KEY | UUID identifier |
| `email` | `VARCHAR(255)` | UNIQUE, NOT NULL | Analyst email address |
| `hashed_password` | `VARCHAR(255)` | NOT NULL | Salted PBKDF2-HMAC-SHA256 password hash |
| `full_name` | `VARCHAR(255)` | NOT NULL | Analyst display name |
| `role` | `VARCHAR(50)` | DEFAULT 'analyst' | `admin`, `analyst`, or `viewer` |
| `is_active` | `BOOLEAN` | DEFAULT TRUE | Account state |
| `created_at` | `DATETIME` | DEFAULT UTC | Registration timestamp |

---

### 2. `threat_indicators` Table
Stores normalized STIX 2.1-compliant cyber threat indicators with merged provenance.

| Column | Type | Description |
|---|---|---|
| `id` | `VARCHAR(36)` (PK) | UUID identifier |
| `type` | `VARCHAR(50)` | `ip`, `domain`, `url`, `sha256`, `sha1`, `md5`, `cve` |
| `value` | `VARCHAR(500)` | Indicator observable value |
| `threat_category` | `VARCHAR(100)` | Function (e.g. `Command and Control`, `Phishing`, `Exploit Probe`) |
| `confidence` | `FLOAT` | Confidence score (0.0 - 100.0) |
| `severity` | `VARCHAR(50)` | `CRITICAL`, `HIGH`, `MEDIUM`, `LOW` |
| `risk_score` | `FLOAT` | Calculated contextual score (0.0 - 100.0) |
| `first_seen` | `DATETIME` | Initial observation timestamp |
| `last_seen` | `DATETIME` | Most recent telemetry timestamp |
| `description` | `TEXT` | Telemetry narrative |
| `sources` | `JSON` | List of attributed intelligence feeds |
| `tags` | `JSON` | Associated actor/malware context tags |
| `cve_references` | `JSON` | Associated CVE identifiers |
| `mitre_techniques`| `JSON` | Associated ATT&CK technique IDs |
| `duplicate_count` | `INTEGER` | Number of multi-source collisions merged |

---

### 3. `threat_relationships` Table
Stores directional edges connecting nodes in the threat graph.

| Column | Type | Description |
|---|---|---|
| `id` | `VARCHAR(36)` (PK) | UUID identifier |
| `source_val` | `VARCHAR(500)` | Origin entity value |
| `target_val` | `VARCHAR(500)` | Destination entity value |
| `relationship_type`| `VARCHAR(100)` | `RESOLVES_TO`, `HOSTS`, `INDICATES`, `EXPLOITS`, `USES_TECHNIQUE`, etc. |
| `confidence` | `FLOAT` | Relationship confidence score |
| `evidence` | `TEXT` | Empirical forensic justification |
| `source_ref` | `VARCHAR(255)` | Telemetry origin |
| `timestamp` | `DATETIME` | Correlation discovery timestamp |

---

### 4. `alerts` Table
Stores prioritized security alerts generated by graph correlation.

| Column | Type | Description |
|---|---|---|
| `id` | `VARCHAR(36)` (PK) | UUID identifier |
| `title` | `VARCHAR(500)` | Incident headline |
| `description` | `TEXT` | Summary of intrusion activity |
| `severity` | `VARCHAR(50)` | `CRITICAL`, `HIGH`, `MEDIUM`, `LOW` |
| `risk_score` | `FLOAT` | Multi-factor risk evaluation (0-100) |
| `status` | `VARCHAR(50)` | `New`, `Investigating`, `Confirmed`, `False Positive`, `Resolved` |
| `affected_indicators`| `JSON` | Array of interconnected IOC values |
| `evidence_chain` | `JSON` | Structured 5-step explainable evidence array |
| `recommended_actions`| `JSON` | Recommended defensive containment steps |
